# باشگاه والیبال فراز — فرانت‌اند React

بازنویسی جداگانهٔ قالب باشگاه والیبال فراز با **React + Vite**. این پروژه فقط فرانت‌اند است و هیچ بک‌اند، API، پایگاه‌داده یا درگاه پرداختی ندارد. پوشهٔ مخزن Django اصلی دست‌نخورده باقی مانده است.

## اجرا

```bash
npm install
npm run dev
```

برای ساخت نسخهٔ نهایی:

```bash
npm run build
npm run preview
```

## صفحات پیاده‌سازی‌شده

- صفحهٔ عمومی باشگاه: معرفی، عضویت، برنامهٔ تمرین، گالری، مربیان، دیدگاه‌ها، تعرفه‌ها، پرسش‌های متداول و تماس
- ورود نمایشی بازیکنان
- داشبورد
- برنامهٔ تمرین
- حضور و غیاب و تقویم
- شهریه و سوابق پرداخت نمایشی
- بیمهٔ ورزشی
- پیشرفت و دستاوردها
- اعلانات
- پروفایل
- تنظیمات
- پشتیبانی

## امکانات رابط کاربری

- فارسی و راست‌چین، فونت‌های محلی Vazirmatn و Space Grotesk
- پوستهٔ روشن و تیره با ذخیره‌سازی انتخاب کاربر در مرورگر
- منوی کناری دسکتاپ و منوی کشویی موبایل
- چیدمان واکنش‌گرا، جست‌وجوی پنل، اعلان‌ها و پیام‌های بازخورد
- فرم‌های نمایشی و داده‌های نمونه؛ تغییرات محلی در `localStorage` مرورگر نگهداری می‌شوند
- پرداخت، ورود، بیمه، گزارش پشتیبانی و سایر عملیات واقعی انجام نمی‌شوند

## ورود نمایشی

در `/login` هر نام کاربری و رمز غیرخالی پذیرفته می‌شود؛ اطلاعات ورود به هیچ سرویسی ارسال نمی‌شوند.

## ساختار

- `src/pages/` — صفحات عمومی و پنل
- `src/components.jsx` — اجزای مشترک رابط کاربری
- `src/context.jsx` — تم، پروفایل، داده‌های محلی و پیام‌ها
- `src/data.js` — داده‌های نمونهٔ باشگاه
- `src/styles/` — استایل صفحات و واکنش‌گرایی
- `public/assets/` — عکس و فونت‌های محلی
